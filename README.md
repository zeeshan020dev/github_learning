# Hello, World! 👋

A simple Python program that prints **"Hello, World!"** to the console.

## 📄 Code

```python
print("Hello, World!")
```

## ▶️ Output

```text
Hello, World!
```

## 🚀 How to Run

1. Make sure Python is installed.
2. Save the code in a file named `hello.py`.
3. Open a terminal or command prompt.
4. Run:

```bash
python hello.py
```

> If you're using Python 3 and `python` doesn't work, try:

```bash
python3 hello.py
```

## 📚 What This Program Does

- Uses Python's built-in `print()` function.
- Displays the message **"Hello, World!"** on the screen.
- Commonly used as the first program when learning a new programming language.
